Features

Everything you need from a modern clock widget, nothing you don't.

🎨

Multiple Themes

Choose from Classic, Neon, Pastel, Dark, and Minimal themes. Create your own with simple JSON.

⚡

Smooth Animation

Silky 60fps hand movement using requestAnimationFrame. No stepping, no jank.

📱

Fully Responsive

Scales perfectly from smartwatch size to 4K displays. SVG-based for crisp rendering at any resolution.

🌙

Dark & Light Mode

Toggle between dark and light modes. Preferences are saved automatically.

🔧

Customizable

Change hand style, dial markings, show/hide elements. Every aspect is configurable.

📡

Works Offline

Zero dependencies, no CDN, no API calls. Runs entirely in the browser.

Why TempoDial?

Built for developers who value simplicity and quality.

  • ✓ Zero dependencies — just HTML, CSS, JS
  • ✓ Under 25KB total (unminified)
  • ✓ Accessible — ARIA labels, keyboard support
  • ✓ Respects prefers-reduced-motion
  • ✓ localStorage settings persistence
  • ✓ Clean, modular, documented code
  • ✓ MIT License — use it anywhere
